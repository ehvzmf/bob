# 법인카드 양식 내보내기 가이드

## 요약
- 회사 양식 파일은 공개 저장소 또는 `public/` 폴더에 두지 않는다.
- 실제 템플릿은 비공개 경로 또는 회사 내부 storage에 보관한다.
- 앱은 브라우저에서 템플릿을 읽어 값만 채우고 새 파일로 다운로드한다.
- 원본 템플릿을 깨뜨리지 않고 복사본을 수정해 export 한다.

## 현재 확인된 구조
현재 확인된 템플릿 파일은 `public/corp-card-template.xlsx`이며, 실제 워크시트 구조를 확인했다.

- 시트 이름: `202501`
- 데이터 영역: `B2:I35`
- 머리글 영역:
  - `B4` ~ `I4`: 컬럼명
  - `B35` ~ `I35`: 합계 영역
- 실제 shared strings에서 확인된 항목:
  - `법인카 드`
  - `계정과목`
  - `승인일자`
  - `고객사명`
  - `가맹점명`
  - `금액`
  - `비고`
  - `연번`
  - `적요(사 용내역)`
  - `합      계`

## 보안 정책
- 공개 저장소에 실제 회사 양식 파일을 올리지 않는다.
- `public/`에는 안내 이미지와 공개 문서만 둔다.
- 템플릿 파일은 로컬 비공개 경로, 환경 변수 경로, 또는 회사 내부 Firebase Storage에 두어야 한다.
- `Hosting`은 정적 파일을 공개하므로, 내부 양식 파일을 Hosting에 올리면 안 된다.

## 운영 방식
### 옵션 A: 로컬 비공개 파일
- 양식 파일을 프로젝트 밖에 두고, 앱에서 사용자 업로드 방식으로 선택한다.
- 장점: 구현이 빠르고 안전하다.
- 단점: 사용자가 매번 파일을 올려야 한다.

### 옵션 B: 회사 내부 Firebase Storage
- Firebase Auth로 회사 계정만 로그인 허용
- Storage에 템플릿 파일을 비공개로 저장
- 앱은 로그인 후 파일 다운로드
- 장점: 사용자 경험이 좋다.
- 단점: Firebase Storage / 인증 설정이 필요하며 비용이 생길 수 있다.

## 권장 결론
- 지금은 옵션 A를 기본으로 두는 것이 가장 현실적이다.
- 이후 회사 내부 서비스가 안정화되면 옵션 B로 전환한다.

## 구현 전략
### 1. 템플릿 위치 정의
- 로컬 업로드 파일 또는 비공개 Storage URL
- 앱은 해당 파일을 불러와 값만 채운다.

### 2. 셀 매핑 정의
- 실제 구조를 기반으로 값이 들어갈 셀을 명시한다.
- 예시:
  - `B4` ~ `I4`: 헤더
  - 데이터는 보통 `B5:I34` 범위에 채운다.
  - 합계는 `G35` 또는 `I35` 같은 위치를 확인해 사용한다.

### 3. 값 채우기
- 본 앱의 내역을 순회하면서 행을 채운다.
- 항목을 `계정과목` 또는 `비고`에 맞게 매핑한다.
- 금액은 숫자만 쓰고, 날짜는 `YYYY-MM-DD` 또는 해당 형식에 맞게 변환한다.

### 4. 다운로드
- 원본 템플릿을 복사해 새 Blob을 만든 뒤 다운로드한다.
- `jszip`으로 zip 내부 XML을 수정하고 다시 zip으로 생성한다.

## 기술 선택
- 현재 권장 라이브러리: `jszip`
- 이유: `.xlsx`를 zip 기반으로 조작해 수식/서식 유지에 유리하다.
- `xlsx` 라이브러리도 가능하지만, 템플릿의 기존 서식/수식을 보존하는 데는 `jszip`이 더 정교하다.

## 체크리스트
- [ ] 템플릿 파일은 `public/`에 두지 않는다.
- [ ] 실제 양식은 비공개 경로 또는 내부 storage에서 관리한다.
- [ ] 앱에서 파일 업로드 또는 인증 기반 다운로드를 지원한다.
- [ ] export 로직은 원본 템플릿 복사본을 만든다.
- [ ] 필요 셀 위치를 별도 설정 파일로 정의한다.
- [ ] 내보내기 전 사용자 확인 화면을 둔다.

## 제출 필드
- 제목: `N월 법인카드 사용내역서`
- 제출자 이름: 설정의 `제출자 이름`을 템플릿의 이름 칸에 채운다.
- 기간: 선택한 월의 `YYYY / MM / 01 ~ YYYY / MM / 말일`
- 계정과목: 기본값 `복리후생비`, 설정에서 변경 가능
- 연번: 내역 순번
- 승인일자: 내역 날짜를 엑셀 날짜 숫자로 변환
- 가맹점명: 내역의 가맹점
- 금액: 내역 금액
- 적요: 내역 항목 `식대` 또는 `음료`
- 비고: 내역 적요

## 저장 위치
- 실제 템플릿은 `private/templates/corp-card-template.xlsx`에 보관한다.
- `private/`와 `*.xlsx`는 모두 `.gitignore` 대상이다.
- 앱은 공개 템플릿을 읽지 않고 사용자가 비공개 템플릿 파일을 선택한다.

## 수식 보존 원칙
- `G35`의 합계 수식은 유지한다.
- 데이터 행은 `B5:I34` 범위만 채우고 기존 서식과 행 구조는 유지한다.
- 수식 재계산 옵션을 켜서 다운로드한 파일을 열면 합계가 갱신되게 한다.
