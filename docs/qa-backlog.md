# QA 및 추가 기능 백로그

## 지금 확인할 것

- 로그인한 Google 계정의 displayName이 제출자 이름에 기본 입력되는지 확인
- 로그인 후 내역·설정이 Firestore `users/{uid}/state/main`에 저장되는지 확인
- 엑셀 내보내기 파일을 실제 엑셀에서 열어 서식·합계 수식·인쇄 설정 확인
- GitHub Actions 배포 성공 여부 확인
- 배포 주소에서 Google 로그인과 Firestore 동작 확인
- 이미지/OCR로 실제 카드 내역 캡처를 가져와 인식되는지 확인
- 영수증 이미지로도 날짜·금액·가맹점이 인식되는지 확인

## 우선 추가 기능

- 로그인 이름 기본값 사용: 이미 로그인 이름을 제출자 이름으로 기본 채운다. 설정에서 수정 가능하게 유지
- 엑셀 내보내기: 실제 양식 검증 후 합계 수식 범위와 30건 초과 규칙 확정
- OCR 강화: 실제 카드 화면 캡처와 영수증 예시 사진을 기준으로 파서와 미리보기 튜닝
- 레시피/매장 정보: 자주 간 가맹점과 최근 카페 빈도 반영
- 메뉴 추천 문장: 예산 티어에 맞는 자연스러운 형용사/명사 조합으로 정리
- 지도 연동 검토: 자주 방문한 가맹점과 평점 좋은 장소를 지도에 표시
- 양식 보관 검토: IndexedDB 우선 보관 유지, 필요 시 Firebase Storage 비공개 전환
- 도메인 제한: 기본 회사 도메인 `shiftone.kr` 제한 적용

## 백로그 아이디어

- 지도 API로 자주 방문한 식당과 평점 좋은 식당 표시
- 영수증 촬영 후 직접 입력을 대신해 내역 시트에 미리보기로 채우기
- 오늘 이미 입력한 식대가 있을 때 하루 사용 가능 금액을 다음날 기준으로 자연스럽게 안내
- 커피만 쓴 날짜와 식사한 날짜를 구분해 추천 문구에 반영
- 자주 간 카페명을 추천 카드에 보조 정보로 표시

## 실제 사진이 필요한 항목

- 하나카드 내역 화면 캡처 2~3장
- 영수증 사진 2~3장
- 개인 식별 정보는 가리고 제출
- 인식 성공 예상 가맹점명/날짜/금액을 메모
